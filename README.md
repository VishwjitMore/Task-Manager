# Task Manager – Full Stack (TypeScript)

A full-stack Task Manager application built with **React + TypeScript** on the frontend and **Express + TypeScript + MongoDB** on the backend. The project focuses on clean architecture, type safety, and real-world CRUD workflows.

## 🚀 Features
- Create, read, update, and delete tasks
- Mark tasks as completed
- Type-safe API and frontend integration
- Clean UI built with Tailwind CSS
- Proper async/await handling and error states

## 🛠 Tech Stack
**Frontend**
- React
- TypeScript
- Axios
- Tailwind CSS
- React Router

**Backend**
- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
